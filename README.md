# Project Management — Feedback

Welcome! This repository is the public place to report bugs and suggest improvements for the **Project Management** application, created by **DocuMan**.

The app is a local-first project and task manager. It helps you organize projects and tasks, track due dates and progress, filter your task list, and import or export tasks using CSV files.

## Share feedback

- **Report a bug:** [Open a bug report](../../issues/new?template=bug_report.md)
- **Suggest an improvement:** [Request a feature](../../issues/new?template=feature_request.md)

If those links don’t work, use the **Issues** tab and choose **New issue**.

When reporting a bug, please include:
- what you were trying to do
- what happened and what you expected to happen
- steps to reproduce the problem
- your operating system and, if relevant, browser
- any error message, with personal or sensitive information removed

For suggestions, describe the problem you’re trying to solve and what would make the app more useful.

## Privacy

Issues and comments in this repository are public. **Do not post passwords, private project or task data, database files, personal contact details, or other sensitive information.** If you need to share a CSV example, replace real names and details with fictional data first.

## About this repository

This repository is for feedback about the app. It is separate from the application’s source code; the source code is not published here. The app is created by **DocuMan**. Feedback is welcome, but a response or implementation is not guaranteed.

Thanks for helping improve the Project Management app!
